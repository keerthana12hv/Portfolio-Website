Featured Projects

ApplyFlow

Students routinely miss placement interviews because recruitment emails get buried in their inbox. ApplyFlow fixes this — it connects to Gmail via OAuth, uses Gemini AI to parse recruitment emails and extract company, role, and interview details, then automatically creates Google Calendar events so nothing slips through. Built with Spring Boot, React, and PostgreSQL, with a Kanban dashboard to track application status end-to-end.

Spring Boot React Gemini API Gmail API PostgreSQL

Placement & Internship Management System (PIMS)

A production-style placement platform that simulates how a real college placement cell would work digitally. Built a custom JWT authentication filter from scratch — no default Spring Security form login — to enforce stateless, role-based access across three roles (Student, Company, Admin). Business rules like CGPA checks, application deadlines, and ownership validation are enforced at the service layer, not the controller, keeping the architecture clean. Deployed with Docker on Render with Neon PostgreSQL and a Netlify frontend.

Java Spring Boot PostgreSQL JWT Docker

LawGlance – RAG Legal Assistant

Indian legal documents are dense and inaccessible to most people. LawGlance makes them queryable in plain English. The pipeline ingests verified legal texts — Consumer Protection Act, IT Act, Fundamental Rights — chunks and embeds them using Sentence Transformers (all-MiniLM-L6-v2), indexes them with FAISS for fast similarity retrieval, and passes the retrieved context to an LLM to generate structured, point-wise answers. Built with Python and Streamlit, deployed on Streamlit Cloud.

Python FAISS Sentence Transformers Groq LLM Streamlit
GitHub Live Demo

Murf AI Voice Studio

An early exploration into integrating third-party AI APIs — combining Murf AI for text-to-speech with multiple voice and accent options, and AssemblyAI for real-time speech-to-text transcription. Features an Echo Bot mode where spoken input is transcribed and played back as an AI voice. Built with FastAPI on the backend and a responsive HTML/CSS/JS frontend, deployed on Render.
